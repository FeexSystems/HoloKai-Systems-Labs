# HoloKai Observability & Telemetry

System monitoring, performance budget enforcement, and self-healing telemetry:
- `observability/logs`: Structured JSON logs with correlation IDs
- `observability/metrics`: Core Web Vitals (CWV) & MFE performance metrics
- `observability/tracing`: Distributed OpenTelemetry tracing streams
- `observability/dashboards`: Grafana & Prometheus dashboard manifests
