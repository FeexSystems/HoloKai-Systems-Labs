# HoloKai Edge Intelligence Layer

This directory contains Cloudflare Workers and Edge Functions:
- `edge/geo-router-worker`: Geolocation routing and region optimization
- `edge/ssr-worker`: Streaming SSR at global edge PoPs
- `edge/mfe-manifest-worker`: Dynamic micro-frontend manifest resolution
- `edge/ai-router-worker`: Predictive navigation & inference caching
