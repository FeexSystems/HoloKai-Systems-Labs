# HoloKai Monorepo Applications Directory

This directory contains the micro-frontend applications for the Planetary UI Platform:
- `apps/shell`: Micro-frontend orchestrator host
- `apps/web-home`: Public landing & vision portal
- `apps/web-oracle`: Oracle AI research portal MFE
- `apps/web-archive`: Civilization Archive MFE
- `apps/web-research`: Research portfolio & journal MFE
