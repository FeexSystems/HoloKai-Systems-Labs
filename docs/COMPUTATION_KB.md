# HoloKai Computational Knowledge Base

Wolfram is the deterministic computation subsystem, not the historical source of truth.

## Engines
- Chronology: BCE/CE intervals, calendar conversions, event ordering, reign durations, uncertainty intervals.
- Geography: distance, bearing, route calculations, coordinate normalization and spatial comparisons.
- Astronomy: celestial coordinates, solar/lunar/planetary calculations, rise/set and orbital geometry.
- Quantitative comparison: ratios, percentages, normalized measures, uncertainty propagation.
- Graph computation: paths, connected components, centrality, clustering and temporal graph measures.
- Units: distance, area, mass, volume, time and temperature normalization.

Every computation should persist:
tool, operation, input, normalized input, result, units, assumptions, timestamp, engine version and source claim IDs.

Keep evidence classes separate:
historical_evidence, computed_result, model_inference, community_oral_record, secondary_interpretation.
