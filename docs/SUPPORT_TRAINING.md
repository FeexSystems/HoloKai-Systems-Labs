# HoloKai Support Team Training Guide

## Overview

This guide provides comprehensive training for the HoloKai support team to effectively assist customers with all aspects of the platform.

- Purpose-built for historical accuracy, not a general AI assistant

### Module 2: Technical Troubleshooting (3 hours)

#### 2.1 Account Issues

**Common Issues**:

**Problem**: User can't log in
**Solution**:
1. Verify email/password
2. Check for account lockout (too many failed attempts)
3. Reset password via email
4. Check if account is suspended (billing issue)
5. Verify email is confirmed

**Problem**: User can't upgrade tier
**Solution**:
1. Check payment method validity
2. Verify billing information
3. Check for subscription conflicts
4. Clear browser cache
5. Try different browser

**Problem**: User can't cancel subscription
**Solution**:
1. Verify account ownership
2. Check for active commitments
3. Process cancellation with effective date
4. Confirm cancellation email sent
5. Explain data retention policy

#### 2.2 Voice Oracle Issues

**Common Issues**:

**Problem**: Voice input not working
**Solution**:
1. Check microphone permissions
2. Verify browser supports Web Audio API
3. Test microphone in system settings
4. Check for background apps占用 microphone
5. Try different browser (Chrome recommended)

**Problem**: Voice output not playing
**Solution**:
1. Check audio output device
2. Verify volume is not muted
3. Check browser audio permissions
4. Test with different voice persona
5. Clear browser cache

**Problem**: Poor transcription accuracy
**Solution**:
1. Check microphone quality
2. Reduce background noise
3. Speak clearly and at normal pace
4. Verify correct language selected
5. Check internet connection stability

**Problem**: Voice response too slow
**Solution**:
1. Check internet speed (min 5 Mbps)
2. Close other tabs consuming bandwidth
3. Check server status page
4. Try shorter queries
5. Report if consistently slow

#### 2.3 Vision Engine Issues

**Common Issues**:

**Problem**: Image generation fails
**Solution**:
1. Check query complexity (simplify if needed)
2. Verify account tier limits
3. Check server status
4. Try different prompt phrasing
5. Report with error message

**Problem**: Generated image inaccurate
**Solution**:
1. Refine prompt with more specific details
2. Use historical context in prompt
3. Try different style options
4. Provide reference images if available
5. Report for model improvement

**Problem**: Generation takes too long
**Solution**:
1. Check internet connection
2. Verify not at tier limits
3. Check server load
4. Try simpler requests
5. Report if consistently slow

#### 2.4 Knowledge Archive Issues

**Common Issues**:

**Problem**: Document upload fails
**Solution**:
1. Check file size limits
2. Verify file format supported
3. Check available storage
4. Try smaller file first
5. Check for corrupted file

**Problem**: Search returns no results
**Solution**:
1. Check query spelling
2. Try broader search terms
3. Verify documents are indexed
4. Check search filters
5. Re-index documents if needed

**Problem**: Metadata not auto-tagging
**Solution**:
1. Check document format
2. Verify document has readable text
3. Check for scan-only PDFs
4. Try OCR if available
5. Manually tag as fallback

#### 2.5 API Issues (Enterprise)

**Common Issues**:

**Problem**: API key not working
**Solution**:
1. Verify key is correct
2. Check key hasn't expired
3. Verify key permissions
4. Regenerate key if needed
5. Check rate limits

**Problem**: API returns 429 errors
**Solution**:
1. Check rate limits
2. Implement exponential backoff
3. Upgrade tier if needed
4. Cache responses appropriately
5. Contact for custom limits

**Assessment**: Troubleshoot 5 simulated customer issues

### Module 3: Customer Communication (2 hours)

#### 3.1 Communication Principles

**Guidelines**:
- Be empathetic and patient
- Explain technical concepts simply
- Never make the customer feel stupid
- Admit when you don't know
- Follow up on promises

**Example Responses**:

**Good**: "I understand how frustrating that must be. Let me help you resolve this step by step."

**Bad**: "You should have read the documentation."

**Good**: "That's a great question. Let me find the answer for you."

**Bad**: "That's obvious."

#### 3.2 Handling Difficult Customers

**Strategies**:
- Listen actively without interrupting
- Acknowledge their frustration
- Focus on solutions, not blame
- Set boundaries if needed
- Escalate when appropriate

**De-escalation Techniques**:
- "I can see why this is important to you."
- "Let's work together to solve this."
- "I want to make sure we get this right."

#### 3.3 Writing Support Emails

**Structure**:
1. Greeting (personalized)
2. Acknowledge the issue
3. Explain the solution clearly
4. Provide step-by-step instructions
5. Offer additional help
6. Professional closing

**Template**:
```
Subject: Re: [Issue Summary]

Hi [Customer Name],

Thank you for reaching out about [issue]. I understand how [impact] this is causing.

Here's how we can resolve this:
[Step 1]
[Step 2]
[Step 3]

Please let me know if you need any clarification or if this doesn't resolve the issue.

Best regards,
[Your Name]
```

**Assessment**: Write 3 support emails for different scenarios

### Module 4: Escalation Procedures (1 hour)

#### 4.1 When to Escalate

**Escalate When**:
- Issue is beyond your knowledge
- Customer is threatening legal action
- Technical issue requires engineering
- Customer requests manager
- Issue affects multiple customers
- Security concern

#### 4.2 Escalation Process

**Steps**:
1. Document the issue thoroughly
2. Attempt initial resolution
3. Determine appropriate escalation level
4. Contact escalation point
5. Follow up with customer
6. Close loop after resolution

**Escalation Levels**:
- Level 1: Senior support agent
- Level 2: Support manager
- Level 3: Engineering team
- Level 4: Executive team

#### 4.3 Emergency Procedures

**Definition**: Service-wide outage or security breach

**Steps**:
1. Acknowledge immediately
2. Provide estimated resolution time
3. Regular status updates (every 30 min)
4. Post-incident communication
5. Compensation if applicable

**Assessment**: Role-play an escalation scenario

### Module 6: Common Scenarios (2 hours)

#### Scenario 1: New User Onboarding

**Customer**: "I just signed up, where do I start?"

**Response**:
1. Welcome them warmly
2. Ask about their goals
3. Recommend starting feature based on goals
4. Provide step-by-step guidance
5. Offer follow-up support

#### Scenario 2: Billing Question

**Customer**: "I was charged but didn't use the service."

**Response**:
1. Acknowledge concern
2. Review account activity
3. Explain billing cycle
4. Offer refund if appropriate
6. Suggest cancellation if not needed

#### Scenario 3: Feature Request

**Customer**: "Can you add X feature?"

**Response**:
1. Thank them for feedback
2. Document the request
3. Check if already on roadmap
4. Explain prioritization process
5. Offer workaround if available

#### Scenario 4: Technical Issue

**Customer**: "The voice feature isn't working."

**Response**:
1. Gather specific details
2. Troubleshoot systematically
3. Escalate if needed
4. Follow up on resolution
5. Document for future reference

#### Scenario 5: Enterprise Inquiry

**Customer**: "We're interested in Enterprise for our company."

**Response**:
1. Express enthusiasm
2. Gather company details
3. Schedule demo with sales team
4. Provide preliminary information
5. Ensure smooth handoff
