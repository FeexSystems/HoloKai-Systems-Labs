# HoloKai Evaluation Protocol

Retrieval:
Recall@5, Recall@10, Precision@5, nDCG@10, MRR, source diversity, graph expansion usefulness.

Grounding:
claim support rate, citation precision, citation completeness, unsupported-claim rate, abstention quality.

Test classes:
single-source, cross-document, multi-hop, chronology, geography, astronomy, competing historiographies, oral tradition, multilingual aliases, colonial archive bias, insufficient evidence and adversarial premises.

Do not approve releases on answer fluency alone.
