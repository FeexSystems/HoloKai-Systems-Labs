# HoloKai Physical Asset Registry

Assets should map a HoloKai semantic entity to a physical/simulation representation.

Recommended metadata:

- `entityId`
- `semanticType`
- `sourceId`
- `epistemicStance`
- `confidence`
- `license`
- `assetUri`
- `usdPath`
- `scale`
- `coordinateFrame`
- `historicalPeriod`

This registry is the bridge between the civilization knowledge graph and OpenUSD/Isaac scenes.
